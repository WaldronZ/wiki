# AutoPaperReader Long-Term Preferences

- 正式入库的论文报告必须走深度分析流程，不接受只做快速摘要。
- 报告质量应对齐原先 Claude Code / Codex 仓库 agent 工作流：先读源码和图表，再写阅读札记、批判性分析，最后生成正式报告并校验。
- 图表必须放在对应论证位置；架构图放在方法细节，主结果表放在实验，限制或失败案例相关图放在批判性分析。
- 如果论文图是 TikZ / LaTeX 绘制而不是独立图片文件，不能说论文没有图；应使用本地 PDF 兜底预览，并在图下写解读。
- 知识库界面应展示真实任务、真实论文和真实中间产物，不使用演示数据伪装进度。
- 后续产品目标是正式本地论文知识库应用，不再按 MVP 玩具标准取舍。
